# v1.0.0 里程碑 — IP Management System

> 硬件 IP 核集成设计工具（对标 Vivado IP Integrator）的 v1.0.0 发布里程碑。
> 当前版本采用**纯前端本地文件网页（模式1）**架构：原生 JavaScript ES6 Modules + HTML5 Canvas 2D + 本地 JSON 文件。

---

## 里程碑 1: 项目基础架构 (M1)

- **时间**: 第 1 周
- **目标**: 完成纯前端项目骨架与基础数据模型
- **交付物**:
  - [x] 项目目录结构（index.html / css / src / data / docs）
  - [x] 原生 ES6 Module 工程化结构
  - [x] 基础数据模型：`IPEntity`、`BDCell`、`BDConnection`、`AddressRegion`
  - [x] 示例数据：`data/ip_catalog.json`、`data/interface_templates.json`、`data/designs/design_1.json`
  - [x] 暗色 Vivado 风格基础样式
- **验收标准**: 直接打开 `index.html` 可加载 IP 目录与示例设计

---

## 里程碑 2: IP Catalog 核心 (M2)

- **时间**: 第 2-3 周
- **目标**: 完成 IP 目录的浏览、搜索、管理与导入
- **交付物**:
  - [x] IP 目录 CRUD 服务（`IPCatalogService`）
  - [x] 分类过滤与关键词搜索
  - [x] VLNV 四元组唯一性检查与版本冲突检测
  - [x] IP 详情弹窗（接口/参数/寄存器映射）
  - [x] 外部 IP 导入：`.json`、`.xci`、`.xml`（IP-XACT）
  - [x] 接口模板库（AXI4 / AXI4-Lite / AXI4-Stream / Clock / Reset）
- **验收标准**: 可导入新 IP、搜索过滤、检测同名同版本冲突

---

## 里程碑 3: Block Design 画布 (M3)

- **时间**: 第 4-6 周
- **目标**: 完成 Block Design 可视编辑与连接管理
- **交付物**:
  - [x] HTML5 Canvas 2D 渲染器（网格、Cell、端口、贝塞尔连线）
  - [x] 鼠标交互：拖拽 Cell、滚轮缩放、Alt/中键平移、Fit 自适应
  - [x] 端口点击-拖动-释放创建接口连接
  - [x] 连接线选中与高亮、Delete 删除
  - [x] 智能 Auto Connect（同类型 Master→Slave 自动匹配）
  - [x] IP 实例化（双击/拖拽）与唯一实例名生成
  - [x] 属性面板：实例信息、参数编辑、寄存器表、地址映射
- **验收标准**: 可完成打开 → 添加 IP → 拖拽 → 连接 → 编辑参数的核心流程

## 里程碑 4: IP Packager 封装向导 (M4)

- **时间**: 第 7-8 周
- **目标**: 完成 6 步 IP 封装向导
- **交付物**:
  - [x] Step 1: 基本信息（VLNV、显示名、分类、标签）
  - [x] Step 2: HDL 源文件管理与 Basic Check
  - [x] Step 3: 接口定义（手动添加 + 模板自动填充）
  - [x] Step 4: 参数配置（bool/long/int/string）
  - [x] Step 5: 寄存器映射与位域定义
  - [x] Step 6: JSON 预览与添加到 IP Catalog
  - [x] 封装后自动保存到本地 JSON
- **验收标准**: 可通过向导创建新 IP 并在 IP 目录中显示与实例化
