# v1.0.0 里程碑

## 里程碑 1: 项目初始化 (M1)
- **时间**: 第 1 周
- **目标**: 完成项目基础架构搭建
- **交付物**:
  - [ ] 项目目录结构
  - [ ] 基础配置文件（pyproject.toml, .gitignore）
  - [ ] Docker 开发环境
  - [ ] CI/CD 流水线配置
- **验收标准**: 本地能运行测试，容器能启动

## 里程碑 2: 核心模型与数据库 (M2)
- **时间**: 第 2 周
- **目标**: 完成数据层开发
- **交付物**:
  - [ ] 数据库模型（IP, Subnet, Device, AuditLog）
  - [ ] Alembic 迁移脚本
  - [ ] 数据访问层（Repository）
  - [ ] 数据库连接池配置
- **验收标准**: 所有 CRUD 操作正常，迁移能运行

## 里程碑 3: 业务逻辑层 (M3)
- **时间**: 第 3-4 周
- **目标**: 完成核心业务逻辑
- **交付物**:
  - [ ] IP 分配/释放服务
  - [ ] 子网管理（CIDR 计算）
  - [ ] 设备绑定管理
  - [ ] 批量操作
  - [ ] 单元测试覆盖率 ≥ 80%
- **验收标准**: 所有业务逻辑通过单元测试
